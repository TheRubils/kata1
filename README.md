# Kata 1
## Objetivo
La finalidad de esta primera kata es la familiarizacion con el entorno de trabajo de IntelliJ IDEA y la reduccion de friccion a la hora de programar mediantes los atajos que nos ofrecen.
## Analizacion del codigo (pasos a seguir)
Para empezar se deberá dirigir a la opcion de **Clone Repository** en su entorno de desarrollo IntelliJ IDEA y poner el enlace al repositorio correspondiente (https://github.com/TheRubils/kata1.git) sabiendo que se esta usando Oracle OpenJDK 25. Una vez dentro podra observar que hay dos clases creadas:
- Person - representación de una persona con su nombre y fecha de nacimiento (campos), calculando su edad aproximada en años.
- Main - Punto de entrada de la aplicación que instancia un objeto Person y lo imprime en consola para mostrar sus datos y su edad calculada.

Para comprobar el correcto funcionamiento del programa, deberá dirigirse a la clase Main y ejecutar el programa. Se puede realizar de forma manual o mas comodamente presionando _Mayús+F10_.
## Atajos

Para agilizar el trabajo se han realizado varias veces esta practica con la ayuda de los atajos, siendo los siguientes:
- Alt+1 - Carpeta del proyecto
- Alt+0 - Commits | Ctrl+K - Seleccionar todos los cambios | Ctrl+Enter - Realizar commit
- Alt+9 - Repositorio Git
- Alt+Ins - Creacion de nuevas clases
- Alt+Move (left & right) - Desplazamiento lateral entre ficheros abiertos
- Ctrl+Move - Dezplamiento en linea de codigo por palabras
- Mayús+F10 - Ejecucion en terminal del proyecto
